## 💎 Sistema de Puntos - Cómo Funciona

### Conversión
```
200 puntos = $1 USD para el usuario
Mínimo de retiro: 3,000 puntos = $15 USD
```

### Comisión 50/50
```
Offerwall paga: $2.00
├─ Usuario recibe: 200 puntos ($1.00)
└─ Sitio recibe: $1.00 de comisión
```

### Ejemplo Real
```
Usuario completa 30 encuestas
Offerwall paga total: $30.00

Usuario acumula: 3,000 puntos ($15.00)
Tu ganas: $15.00

Usuario solicita retiro: $15.00
Balance final:
├─ Offerwall te pagó: $30.00
├─ Pagaste al usuario: $15.00
└─ Tu ganancia neta: $15.00 ✅
```
