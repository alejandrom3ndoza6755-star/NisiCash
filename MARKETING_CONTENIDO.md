### Para Publicaciones Estáticas:
1. **Capturas de pantalla del dashboard** mostrando puntos acumulados
2. **Mockups de celular** con la interfaz de NisiCash
3. **Infografías**: "200 puntos = $1 USD"
4. **Gráficos de progreso**: "De 0 a $15 en X días"
5. **Imagen del sorteo**: "$100 USD - SORTEO MENSUAL"

### Para Videos:
1. **Screen recording** del proceso de registro
2. **Screen recording** completando una encuesta
3. **Dashboard en acción** mostrando puntos incrementándose
4. **Cara hablando a cámara** + screen recording en pantalla dividida
5. **Transiciones rápidas** (TikTok style)

### Herramientas Recomendadas (Gratis):
- **Canva**: Para crear imágenes y mockups
- **CapCut**: Para editar videos cortos
- **OBS Studio**: Para grabar pantalla
- **Pexels/Unsplash**: Fotos stock gratuitas
