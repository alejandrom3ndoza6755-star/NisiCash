## 📝 Cómo Actualizar Enlaces

### Ubicación en el Código
Los enlaces están en **`index.html`** línea ~602-607:

```html
<div class="social-links">
    <a href="https://www.facebook.com/profile.php?id=61590306975217&locale=es_LA" 
       class="social-link" 
       aria-label="Facebook" 
       target="_blank" 
       rel="noopener noreferrer">
        <i class="fab fa-facebook-f"></i>
    </a>
    <!-- Más enlaces aquí -->
</div>
```

### Pasos para Actualizar

1. **Abrir `index.html`**
2. **Buscar** la sección `<div class="social-links">`
3. **Reemplazar** el atributo `href` con la nueva URL
4. **Guardar** el archivo
5. **Hacer commit:**
   ```bash
   git add index.html
   git commit -m "update: Actualizar enlace de [Red Social]"
   git push origin HEAD:master
   ```
